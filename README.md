# Scripts-Sql Project Structure

This repository contains SQL scripts organized into two main folders:

## v1-original
This folder contains the original SQL scripts that were initially created and used. They represent the starting point and reference for later versions. These scripts may not be optimized and might include experimental queries or functions.

## v2-produccion
This folder includes the production-ready SQL scripts. These scripts are optimized for performance and have been tested for reliability in production environments. They are the recommended version for deployment.

## Conclusion
The separation of folders allows developers and database administrators to access both the original and production versions of each script, ensuring that historical context is maintained while also providing a solid foundation for current and future database operations.
